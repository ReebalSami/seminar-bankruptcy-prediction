Interpretation

RFECV (Recursive Feature Elimination with Cross-Validation):

  • Wrapper method: Uses a model (Logistic Regression) to evaluate feature subsets
  • Recursive elimination: Iteratively removes least important features
  • Cross-validation: Determines optimal number of features via 5-fold CV
  • Advantage: Considers feature interactions (unlike filter methods)
  • Trade-off: Computationally expensive but more accurate

Performance Evaluation:

  • Inner CV: Used for feature selection (avoid overfitting)
  • Outer CV: Independent evaluation of selected features
  • Nested CV: Prevents data leakage and provides unbiased performance estimates
